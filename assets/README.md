# Jev Workflows listing icon

- `jev-workflows-mark.svg`: editable 512 × 512 vector source.
- `jev-workflows-mark.png`: 512 × 512 PNG with alpha, rendered from the SVG.

The original branching-decision mark belongs to this independent community
integration. It does not use the OpenAI or TypeSafe logos and does not imply
approval by either company. The repository's MIT license covers these assets.

The mark shows one input, two possible paths, and one highlighted candidate.
It represents advisory selection, not a certification seal.
