# Native desktop ranking pilot

This maintained offline controller prepares exactly eighteen fixed-profile attempts. It does not launch a model, control Codex, change plugins, or resume an old cohort. Root owns native execution after every gate passes. The approved [specification](../../docs/routing-value-pilot.md) controls scope.

The domain is a frozen manifest, six balanced arm orders, eighteen single-use slots, and an append-only event reducer. Each bug has model-alone, cheap-BM25, and Jev-first arms. Each task's candidates and packet content remain fixed except for order. Graders and reference repairs remain outside coding context.

## Throughput checkpoint

- Blocking first steps. Verify desktop identity, baseline exposure isolation, six disjoint tasks, and broken/reference/absent/wrong grader controls before freeze or coding.
- Independent workstreams. This owner implements new desktop qualification and pilot files. Root owns routing contracts, ranker integration, generated assets, and native execution. The existing benchmark auditor checks preserved reservations without running them.
- Shared mutable state. Each pilot run has one owner and immutable numbered events. Existing cohorts are read-only. Private run evidence stays in an authorized private worktree.
- Smallest safe decomposition. First qualify capability, then freeze identity and validate transitions, then derive observed reports. Unsupported actuation does not prevent a fixed-profile pilot if baseline isolation qualifies.

## Acceptance

The controller refuses missing exposure proof, stale/missing control evidence, old reserved tasks, changed identity, extra attempts, retries, and out-of-order slots. Coding time includes startup, retrieval, approvals, and human waits. Coding stops by minute 35 and terminal-patch grading finishes by minute 45. Invalid infrastructure is a separate result. Missing billing remains null and zero fixes never produce a winning time-per-fix value.

All test fixtures are synthetic. They are not pilot outcomes. The qualification receipt and NOTSTARTED dispositions record current unavailable gates without inventing zero-reward results.

## Repeat the offline checks

Run `node --test benchmarks/desktop-ranking-pilot/*.test.mjs`. Run `npm run typecheck` and `node --import tsx --test tests/desktop-qualification.test.ts` from `source/jev-workflows`. Root owns adding the first command to the final repository CI map.

The acquisition command is `node benchmarks/desktop-ranking-pilot/cli.mjs acquire benchmarks/desktop-ranking-pilot/swebench-verified-source.json .agent-work/desktop-pilot-corpus/swebench-verified.parquet`. The URL includes the immutable dataset revision and its SHA-256 is checked before publication. Run `import-swebench.py` with that artifact, `--repository .`, and a new owned `--output` directory to regenerate metadata. It requires PyArrow. Run `cli.mjs check-corpus` with the regenerated catalog and reservations.

For non-model grader preparation, create an owned environment with Python 3.9 and install `grader-requirements.txt`. The retained controls used Python 3.9.6. Run `preflight.py` with the artifact, `--python` pointing to that environment, an owned `.agent-work` `--work` directory, and a new `--output` directory. It fetches only the six pinned public bases, applies inspected reference or deliberately wrong control patches, and invokes the external grader without HTTP requests. It removes each owned control checkout after retaining the result. Interrupted worktrees must be reconciled before rerun. Existing receipts and log files are never replaced.

Run `cli.mjs prepare` with the catalog, reservations, desktop receipt, current preflight directory, `grade.py`, and a new output directory. It checks controls and generates a status chart and eighteen unstarted dispositions. It does not freeze an execution manifest. All source/data, package, model, permissions, catalog and packet pins still need root's real native qualification before `cli.mjs freeze`.

`cli.mjs record` appends one immutable event with readback. Start is recorded before native startup or retrieval. Record the matching runtime identity, actual packet or unavailable-delivery evidence, approvals and failed public checks, terminal patch, independent grade and observed billing. Each graded event names the frozen grader hash. `cli.mjs status` returns deadlines; `cli.mjs report` writes observed JSON and step SVG. The controller detects late events. The native execution owner must actually stop coding by minute 35 and finish grading within ten minutes and by minute 45. A supported stop mechanism is a native executor prerequisite.

Raw study events and receipts belong in an authorized private worktree. Public export is an explicit sanitized copy. Subscription capacity stays separate from billed dollars. Unknown billing stays null. No helper starts inference or authorizes a follow-up study.
