# Jev Workflows 0.6.0-rc.1

Prepared October 28, 2026. Stable promotion awaits the human review of valid pilot results. This release candidate preserves the eight public tool names, plugin identity, credential mechanism and historical receipts. The existing TypeSafe decision model stays pinned to `jev-1.13.0` unless explicitly configured otherwise.

## Implemented behavior

- Every supplied eligible candidate remains reachable, including positions beyond twelve and fifty. Larger inventories use bounded pages; page-local probabilities are not presented as globally calibrated confidence. Supported discovery follows pagination and records inaccessible categories. A complete supplied inventory does not prove that a host exposes all its tools or models.
- Optional catalog references connect scoped host capabilities, task revisions and eligible model-effort pairs to decisions. Existing direct tool calls retain their meanings. Prepared delivery, host application, actual execution and verified outcome are separate observations.
- Automatic consultation supports `changed_state` and `always`, with a five-second deadline, recoverable duplicate claims and provider-aware cooldown. These controls add no daily, byte or session quota. Fresh automation remains disabled; legacy choices remain intact.
- Task-context and receipt writers share ownership-safe locking. Expired facts, stale revisions, cancellation, pins, interrupted publication and scope mismatches have focused regression checks.
- Claude has an optional native file adapter. Trusted ordinary hooks produce its decisions. Causal completed-tool IDs bind a record to its session and preceding inference. Missing or ambiguous joins retain the incoming profile. It has passed offline checks and the installed static validator. Live Claude inference remains held.

The [feature map](routing-feature-map.md) connects these behaviors to public entrypoints and reproducible checks. [Privacy and retention](../source/jev-workflows/docs/privacy.md) describe the additive local records.

## Capabilities still unfinished

Codex desktop automatic switching is **undelivered**. The installed app was inspected once through supported, read-only surfaces. No supported connection to the runtime owning the desktop task, ordered pre-dispatch application or actual next-request model evidence was established. No private IPC, billing change, alternate coding-model gateway or CLI substitution was used. See the [qualification receipt](../benchmarks/desktop-ranking-pilot/qualification-2026-10-28.json).

Claude native loading, security-guard behavior, actual answering model/effort, live cancellation and usefulness remain unverified. Downshift is deliberately unsupported without completed-subtask evidence. The classic Claude package remains the default; native configuration is explicit opt-in.

Public Git source and generated packages do not establish official-directory acceptance. No marketplace acceptance receipt is available. Existing stable installations are not silently replaced with this candidate.

## Pilot preparation and outcomes

The frozen protocol has six real SWE-bench bugs across Requests and SymPy, three arms and eighteen slots. These tasks are disjoint from the retained old reservations. Source, graders, order, candidate generation and treatment identity must be frozen before scoring.

All twenty-four real grader controls passed their expected results: each broken base, missing repair and wrong repair fails; each reference repair passes. The [grader-control chart](../benchmarks/desktop-ranking-pilot/preparation-2026-10-28-attempt-5/grader-controls-2026-10-28.svg) shows preparation only. Earlier failed preparation receipts remain preserved.

All eighteen coding attempts are [NOTSTARTED](../benchmarks/desktop-ranking-pilot/preparation-2026-10-28-attempt-5/notstarted-2026-10-28.json). The native interface available here cannot yet prove a baseline free of Jev tools, instructions, hooks and transport, or the execution and stopping controls required by the protocol. A plugin-versus-baseline quality chart would therefore be fabricated. No coding model was invoked for this cohort.

The controller retains unsuccessful attempts, abstentions, outages, unknown billing and timing over all assigned attempts. Its charts stop at observed support; ungraded attempts are unknown rather than zero fixes. A larger study, adaptive-model study, Claude inference and QQ work remain paused.

## Reproduce and rollback

Run `node scripts/verify.mjs` on Node 22 or newer. The existing pre-push hook runs the same repository checks inside the retained local CI VM without GitHub-hosted minutes. Generated Codex and Claude packages must match the same source tree. Static native validation is separate from running Claude inference.

Keep the installed stable package and configuration backup when staging this candidate. Preserve shared receipts, sessions and protected credential files. Do not place new code under the old version's cache path. Native hook trust remains a host review. Rollback selects the retained stable package and policy backup; it does not delete state or rewrite receipt history.
